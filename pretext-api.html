Pretext 101

Pretext is a JavaScript library for measuring and laying out text without rendering it in the DOM. It’s fast, accurate, and easy to use.

Core Mental Model / API

prepare() / prepareWithSegments()   →  expensive, doing the normalize whitespace, segments the text.
layout() / layoutNextLine()         →  cheap arithmetic, run on every resize/frame, run to get the line height / width of the text. 

Think of it like a database:

prepare = write to cache (measure all segments via canvas)
layout  = read from cache (pure math, no I/O)

Rule of thumb: prepare once per text+font; layout as often as you want.

Common Functions

prepare(text: string, font: string, options?: PrepareOptions): PreparedText

Analyzes and measures text, caching glyph widths for fast subsequent layout. The returned PreparedText is opaque — pass it to layout().

Parameter Type Description
text string The text to prepare for layout.
font string CSS font shorthand (e.g., “16px Inter”).
options PrepareOptions Optional. { whiteSpace?: "normal" | "pre-wrap" }
Returns: PreparedText — opaque handle for use with layout() 
prepareWithSegments(text: string, font: string, options?: PrepareOptions): PreparedTextWithSegments

Same as prepare but also stores segment metadata. Required for layoutNextLine, materializeLineRange, and walkLineRanges.

Parameter Type Description
text string The text to prepare for segmented layout.
font string CSS font shorthand (e.g., “16px Inter”).
options PrepareOptions Optional. { whiteSpace?: "normal" | "pre-wrap" }
Returns: PreparedTextWithSegments — segments + widths cached 
const prepared = prepareWithSegments('Hello world', '16px Inter')
// prepared.segments → ['Hello', ' ', 'world']
// prepared.widths   → [37.5, 4.4, 28.1]
layout(prepared: PreparedText, maxWidth: number, lineHeight: number): { height: number, lineCount: number }

Pure arithmetic. Returns { height, lineCount } for a given container width.

Parameter Type Description
prepared PreparedText Opaque handle created by prepare().
maxWidth number Maximum line width in pixels.
lineHeight number Line height in pixels.
Returns: { height, lineCount } — summary stats 
const { height, lineCount } = layout(prepared, 300, 24)
// height    → total px height of the text block
// lineCount → number of wrapped lines

Call this on every resize — it’s essentially free. 

layoutNextLine(prepared: PreparedTextWithSegments, cursor: LayoutCursor, maxWidth: number): { text: string, width: number, end: LayoutCursor } | null

Walks one line at a time from the given cursor. Returns { text, width, end } or null when all lines are consumed.

Parameter Type Description
prepared PreparedTextWithSegments Prepared handle created by prepareWithSegments().
cursor LayoutCursor Current cursor (segment + grapheme offset).
maxWidth number Maximum line width in pixels.
Returns: { text, width, end } | null — one line at a time 
let cursor = { segmentIndex: 0, graphemeIndex: 0 }

while (true) {
  const line = layoutNextLine(prepared, cursor, maxWidth)
  if (!line) break         // null = all lines consumed

  console.log(line.text)   // string content of this line
  console.log(line.width)  // measured pixel width

  cursor = line.end        // LayoutCursor for next line
}

cursor is a LayoutCursor: 

type LayoutCursor = {
  segmentIndex: number    // which segment in prepared.segments
  graphemeIndex: number   // which character within that segment (non-zero only for mid-word breaks)
}
walkLineRanges(prepared: PreparedTextWithSegments, maxWidth: number, callback: (line: { text: string, width: number, start: LayoutCursor, end: LayoutCursor }) => void): void

Walks lines from the start, invoking the callback with line content, width, and start/end cursors.

Parameter Type Description
prepared PreparedTextWithSegments Prepared handle created by prepareWithSegments().
maxWidth number Maximum line width in pixels.
callback function Invoked for each line with content, width, and cursors.
Returns: void — callback invoked for each line

Usage API

Fast Path

Use prepare() then layout() to get height and line count.

—

Iterator Path

Use prepareWithSegments() and layoutNextLine() to walk lines.

—
Examples:
import {prepare, layout, prepareWithSegments, layoutNextLine} from '@chenglou/pretext';
