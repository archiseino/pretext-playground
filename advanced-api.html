Pretext Advanced API

Use-case 2: lay out paragraph lines yourself. Render to canvas, shrink-wrap bubbles, flow text around obstacles.

1. layoutWithLines()

Returns actual line strings. Here we draw them to a <canvas> — no DOM text at all.

2. measureLineStats() — shrink-wrap

measureLineStats(prepared, width) returns { lineCount, maxLineWidth } without building line strings. We use it to binary search for the tightest bubble width. There's also walkLineRanges(prepared, width, cb) which calls a callback per line with its width and start/end cursors — useful when you need per-line data rather than just the summary stats.
