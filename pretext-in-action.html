Pretext in Action

Three examples using just prepare() + layout(). Each section is independent.

1. Accordion

Click a section. Pretext computes the open height — the CSS transition animates to it.

2. Virtualized List

10,000 items. Heights computed by Pretext before any DOM insertion. Scroll to see only visible items rendered.

3. "Show More" Line Clamping

layout() returns lineCount. If it exceeds the limit, we clamp and show a toggle.

4. Chat Bubble

A chat bubble that wraps around the maxContainer, demonstrating how Pretext can be used for dynamic text layouts in constrained spaces.
